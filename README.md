# Homebrew Tap for Stackwares

Official Homebrew Tap for Stackwares macOS applications and developer tools.

## Installation

### Flunner

A native macOS workbench for the Flutter run–observe–reload loop.

```bash
# Install Flunner
brew install --cask stackwares/tap/flunner

# Or tap first
brew tap stackwares/tap
brew install --cask flunner
```

To update:
```bash
brew upgrade --cask flunner
```
